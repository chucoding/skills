Notion 페이지 URL이나 UUID가 주어지거나 Notion 문서를 읽고 쓰라는 요청이 있을 때 이 스킬을 적용한다. 수정 전 조회와 최소 범위 수정, Notion 마크다운 규격(`notion://docs/notion-flavored-markdown-spec`) 확인은 Notion MCP 도구 설명을 따르고, 이 스킬은 그 위에 더하는 작성 규칙과 접근 실패 안내만 다룬다.

### 1. Notion용 마크다운

- 테이블은 Notion에서 지원되는 테이블 문법을 사용하고, 셀 안에는 서식 있는 텍스트만 사용한다.
- 특수문자(역슬래시, 별표, 물결표, 백틱, 달러, 대괄호, 꺾쇠괄호, 중괄호, 파이프, 캐럿)는 문맥에 따라 이스케이프한다. 코드 블록 안은 리터럴로 둔다.
- 구분선(`---`)은 새로 만들지 않는다. 섹션은 `#` 제목으로만 나누고, 목록이나 테이블로 구조를 정리한다.
- 기존 페이지에 있는 구분선은 수정 요청 범위에 들어오지 않으면 그대로 둔다.

### 2. 작성 형식

- Notion 페이지에 쓰는 내용은 한국어로 작성한다.
- 섹션은 `#` 제목으로 구분하고, 비교나 정리에는 테이블을 사용한다.
- 예시 코드는 언어 태그를 포함한 코드 블록으로 작성한다.
- 설계 문서, 아키텍처 설명, 데이터 흐름 등을 정리할 때 Mermaid 다이어그램을 적극 활용한다.
  - 컴포넌트/모듈 간 의존 관계
  - 데이터 흐름(API 호출, 번들 분리 등)
  - 시퀀스 다이어그램(사용자 플로우)
  - 아키텍처 결정 비교

### 3. 접근 실패 안내

- 조회나 수정이 권한 문제로 실패하면 사용자에게 Notion URL 확인과 공유 설정(연동 계정 접근 허용)을 안내한다.
