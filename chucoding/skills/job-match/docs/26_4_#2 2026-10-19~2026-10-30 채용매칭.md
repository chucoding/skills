이번 스프린트 회고 `1. 핵심 성과`에 있는 근거의 성과 문장:

- SSR/Next.js, API 계약 설계, E2E 테스트 — 「인쇄 인입을 리포트별 정적 라우트와 gzip payload로 다시 설계해, 합성 2만 행 요청을 6,568KB(413 거부)에서 426KB로 줄였다.」
- CI/CD, 개발 환경 개선 — 「typecheck를 버전 고정한 TS7로 돌리고 build의 중복 tsc를 빼, PR CI를 느린 러너 기준 14%, 빠른 러너 기준 16% 줄였다.」
- 프론트엔드 아키텍처, 레거시 마이그레이션·리팩터링 — 「`shared`가 `features`·`widgets`를 거꾸로 가져오던 의존 두 갈래를 끊어, 인쇄 화면 28곳(호출 38곳)이 출력 이력을 직접 남기고 349파일이 회사·단지 선택을 `shared`에서 구독하게 했다.」
- React Query(서버 상태), 상태 관리 — 「재조회 원인을 무효화와 「조회」 클릭으로 나눠, 저장 뒤 목록이 스켈레톤으로 바뀌어 스크롤이 맨 위로 돌아가던 동작을 12개 화면에서 없앴다.」
- AI 코딩 도구, 코드 리뷰 — 「반복된 리뷰 지적 145건을 군집으로 나눠 AGENTS.md에 없던 상위 군집을 규칙으로 옮기고, 규칙마다 리뷰 코멘트 출처를 달았다.」
